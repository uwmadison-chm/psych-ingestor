# Discussions

Superseded working-out. Design conversations that shaped a decision, kept after the
decision moved somewhere else — an issue, a doc, or the code.

**Nothing here is current.** These are kept for the reasoning, not the conclusions. A
document in this directory has already been overtaken by whatever it points at, and reading
one as though it describes Pig today will mislead you. If you want to know what Pig does,
read `docs/`; if you want to know what Pig will do, read the issues.

Every entry starts with a line saying what superseded it and when. Files are named
`YYYY-MM-DD-topic.md`, dated when the discussion happened rather than when it was filed
here.

The reason to keep them at all: the arguments are usually more valuable than the answers.
When a decision comes back up — and they do — the useful thing to have is what was
considered and rejected, which an issue that's been rewritten no longer shows.
