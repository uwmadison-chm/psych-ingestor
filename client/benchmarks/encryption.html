Pig encryption benchmark

This encrypts sample events and recording-sized parts with the client's own encryption code, in a worker, as the client does for a task that encrypts. Nothing is sent anywhere. Keep the screen on while it runs.

Not run yet. Takes about 10 seconds to a few minutes.

Events

Each is turned into JSON, encrypted, and base64-encoded, which is what the client does with every event. The smallest is nearly all the cost of a call; the large one is nearly all the cost of the bytes.
